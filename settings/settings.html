Welcome to OriginFill — let's set you up (about 5 minutes)

Fill in Personal Info, add your Work Experience and Education, and upload your Resume. Click Save in each section. Then open any Workday application and press the ⚡ Autofill button at the bottom-right of the page — once per step.

💡
For any other question

Type a few words from the question and your answer. A question is answered when all of its words appear in the form's question, e.g. reason for leaving → Career growth. For dropdowns and Yes/No buttons, use the option's wording. These take priority over the common questions above.

Extension Settings

Auto-detect portals Automatically detect job portals when pages load
Auto-fill each new page Fill every application step as soon as it opens (you still review and submit)
Show the Autofill button on application pages A floating ⚡ Autofill button that fills the current step in one click
Replace values already in a field Off: fields that already have a value (e.g. from Workday's résumé parsing) are left alone
Show notifications Browser notifications for session timeouts and fill status
Session recovery Save what you type (never passwords) so it can be restored after a session timeout
Debug logging Write detailed [OriginFill] logs to the page console — useful when reporting a problem
Lower = faster fill, Higher = more reliable on slow pages

Privacy & Data

🔒
Your data is encrypted

All profile data is encrypted with AES-256-GCM and stored locally in your browser. No data is ever sent to external servers.

Export Data

Download all your profiles and settings as a JSON file.

Import Data

Restore from a previously exported JSON file.

Clear All Data

Permanently delete all profiles, settings, and saved data. This cannot be undone.
